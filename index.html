How to read this profile

Thalweg bed: deepest DEM pixel on a ±250 m perpendicular cross-section every 250 m along the centreline (echo-sounded bathymetry, PANGAEA DEM). DEM along SWOT centerline: DEM elevation sampled on the SWOT node centerline. SWOT WSE: node water-surface elevations from a high-flow event () and a low-flow event (); gaps are unobserved sections of those passes. Dashed verticals mark the four gauges at their corrected chainages (0 km = Bingen).

About this digital twin

This dashboard accompanies an MSc thesis on estimating Rhine river discharge from the SWOT satellite mission. Four PegelOnline gauging stations are used as ground truth: Kaub, Bonn, Duisburg-Ruhrort and Wesel.

  • Water level: in-situ stage from WSV PegelOnline (continuous, 15-min) compared with satellite altimetry water levels from DAHITI (DGFI-TUM).
  • Discharge: a modified Manning approach (Durand et al., 2023) driven by SWOT water-surface elevation, width and slope, with the unobserved channel area derived from echo-sounded bathymetry (PANGAEA DEM). Variants: fixed vs SWOT-observed slope, literature vs calibrated roughness.
  • Live layer: the most recent 30 days and the current measurement are fetched directly from the PegelOnline REST API every time the page loads — the "twin" always shows the river's present state.
  • Context models: GloFAS (Copernicus) and GEOGloWS reanalysis discharge can be toggled in the legend of the discharge chart.

3D scene: CesiumJS with Esri World Imagery (or Google Photorealistic 3D Tiles if an API key is configured). Author: Sharvil Upadhye.
